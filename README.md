# SkeletonContext

The model implementation of SkeletonContext is provided in the `model/` directory.

For environment setup, data preparation, pretrained weights, training, and evaluation, please follow the instructions in [Neuron](https://github.com/cseeyangchen/Neuron).

Our training settings and experimental protocols are consistent with Neuron.
